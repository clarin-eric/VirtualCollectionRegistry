The API has support for two types of authentication:

1. User specific API keys, typically used by users when interaction with the API via the command line.
   Header: 
    
    Authorization: <token>

2. JWT token generated by the frontend backend user for interaction with the API on behalf of the user.
   The frontend and rest API share a secret to sign and verify the JWT tokens.
   Header: 
    
    Authorization: Bearer <token>
